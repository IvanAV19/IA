# Inteligencia Artificial (IA)

Repositorio centrado en la exploración y desarrollo de modelos de Inteligencia Artificial, Machine Learning y Deep Learning.

## Objetivo
Centralizar algoritmos, experimentos, modelos entrenados y recursos de estudio para resolver problemas complejos a través de la IA.

## Tecnologías y Herramientas
Python, TensorFlow, PyTorch, Scikit-Learn

## Estructura del Repositorio
* `/modelos`: Modelos preentrenados y scripts de entrenamiento.
* `/notebooks`: Cuadernos de Jupyter con análisis exploratorio y pruebas.
* `/datasets`: Conjuntos de datos utilizados en los proyectos.
